Event pages

Add and edit event pages here, then Preview them before they go live.

How this works

Each event page is a draft, scheduled or live, and is shown at event.html?e=web-address. Until it is live the public only sees a Coming soon card. Preview opens it for you in this browser and stays open until you end it. To show it to others first, press Copy link and send it: they can ask for an emailed code (see Event previews below). Press Save and Preview shows the change straight away. From its publish date it goes live and is featured, with its image and tagline, in the homepage Events section until the event is over. Saves update the live site in about a minute.
